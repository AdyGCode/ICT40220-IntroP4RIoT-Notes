# Response

Certainly! Here's how an 18-year-old newcomer to version control might answer these questions:

---

### c. What disruptions to collaborative work do you think could occur if company personnel were not given these specific instructions?

Without clear instructions on using Git and version control, several issues can arise:

* **Overwriting Each Other’s Work**: Without version control, multiple team members might unknowingly edit the same file simultaneously, leading to lost changes and confusion.

* **Difficulties in Tracking Changes**: Without proper commit messages and branching strategies, it becomes challenging to understand the history of changes, making debugging and collaboration harder.

* **Merge Conflicts**: Without guidance on how to handle merges, conflicts can occur when integrating changes, potentially causing delays and errors.([moldstud.com][1])

* **Lack of Accountability**: Without setting up user identity configurations, it's hard to track who made specific changes, complicating code reviews and accountability.

* **Reduced Efficiency**: Without best practices, workflows can become disorganized, leading to inefficiencies and potential project delays.

---

### d. Why does the organisation need to give you these instructions as opposed to centrally configure them?

While central configurations can set default behaviors, personal configurations are essential for:

* **Personal Preferences**: Developers have individual preferences for tools and workflows. Personal configurations allow them to tailor their environment to their comfort, enhancing productivity.

* **Flexibility in Workflow**: Different projects or tasks might require different settings. Personal configurations provide the flexibility to adapt without affecting the entire team.

* **Avoiding Conflicts**: Central configurations might override personal settings, leading to potential conflicts or disruptions in a developer's workflow.

* **Security and Privacy**: Personal configurations can include sensitive information like user credentials. Central configurations might expose this data, posing security risks.
