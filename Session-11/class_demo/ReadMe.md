# Cat Class/Type Exercises

## Exercise 1: Adding Attributes

Add a coat color attribute to the Cat class.

Instantiate a Cat instance and print the name,
age, and coat_color attributes.

## Exercise 2: Adding Methods

Add a purr method to the Cat class that
prints <name> purrs. 

Call the purr method on the Cat instance.

## Exercise 3: Dog Class/type

Define a class Dog that has a name and an 
age attribute.

Instantiate a Dog instance and print the name
and age attributes.

Test the class by instantiating a dog with 
the name "Rex" and age 3.

## Exercise 4: Adding Methods to Dog Class

Add a bark method to the Dog class that prints
<name> barks.

Call the bark method on the Dog instance.

The dog instance's name will be "Woof", and aged 4
